# 볼링 로그라이크 (가제)

**장르**: 로그라이크 + 스포츠(볼링)

## 1. 게임 구조

- 스테이지제: 목표 점수 이상 달성 시 즉시 클리어 후 다음 스테이지로 진행
  (발라트로처럼 목표 점수 개념을 가져오되, 목표 달성 즉시 클리어라는 점에서 차이)
- 경기 방식: 일반 볼링과 동일하게 총 10프레임, 프레임당 투구 2회
- 투구법: 별도 투구 스타일(폼) 도입 여부 논의 중 (보류)

## 2. 스킬 시스템 (로그라이크 핵심 요소)

### 발동형 (투구 시 확률적으로 발동, 핀에 큰 도움)
| 스킬 | 효과 |
|---|---|
| 지진 | 투구 후 확률적으로 캐릭터가 넘어지며 핀에 데미지 |
| 스탠드 | 다른 캐릭터가 대신 투구 |
| 봅슬레이 | 썰매로 빠른 속도 투구 |
| 더블 | 공 하나가 추가로 같이 날아감 |
| 시한폭탄 | 투구 후 일정 시간 뒤 폭발 |
| 태풍 | 바람으로 주변 핀에 데미지 |
| 오류 | 핀 1개 남았을 때 확률적으로 자동으로 쓰러짐 |
| 벽생성 | 거터 자리에 벽 생성 (일정 횟수 후 소멸) |
| 비 | 레인에 비가 내려 더 미끄러워짐 |
| 리무브 | 낮은 확률로 핀 하나를 즉시 제거 |
| 전류 방출 | 공이 핀 중앙에 도착하면 확률적으로 전류 방출 |

### 상시형 (지속 발동, 보조/증폭 효과)
| 스킬 | 효과 |
|---|---|
| 거구 | 플레이어 몸무게 증가 (지진 스킬에 영향) |
| 불안정한 발 | 넘어질 확률 증가 + 어드밴티지(보상) |
| 스킬 복제 | 복제된 공에도 스킬이 함께 발동 |
| 한번더 | 공 1개 추가 |
| 쌍소멸 | 공끼리 부딪히면 소멸 대신 큰 폭발 발생 |
| 집속탄 | 폭발 후 작은 폭탄 여러 개 추가 생성 |
| 탄성벽 | 벽 반사 횟수 증가 |
| 핀볼 | 벽에 튕길 때마다 데미지 증가 |
| 드리프트 | 봅슬레이 스킬이 드리프트 함 |
| 여진 | 지진 발생 1초 후 한 번 더 지진 발생 |
| 해일 | 해일로 핀을 넘어뜨림 |
| 삼각편대 | 여러 공이 서로 간격을 유지하며 비행 |
| 재시도 | 오류 스킬 발동 실패 시 한 번 더 판정 |
| 해킹 | 오류 스킬 발동 확률 증가 |
| 압축 | 공 크기 감소 + 속도 증가 |
| 거대화 | 공 크기 증가 |
| 철핀 | 모든 핀 재질이 철로 변경 |

## 5. 투구 시스템 (조작 / 물리)

**입력 방식**
- 마우스를 누른 채 뒤로 뺐다가 앞으로 밀며 놓으면 투구
- (대안) 불편하면 앞으로 미는 동작만으로 투구되게 단순화 가능

**궤적 -> 물리 변환**
- 마우스 드래그 경로의 각도를 추적 -> 공의 진행 방향 결정
- 드래그 궤적의 곡률(휘어짐)에 따라 스핀(회전) 값 추가 -> 공이 커브를 그리며 이동
- 마우스 이동 속도 추적 -> 공의 투구 속도 결정

**데미지 공식**
```
충격력 = 속도 x 파운드
데미지 = 충격력 x 힘보정 x 회전보정
```
