# 볼링 로그라이크 (가제)

**장르**: 로그라이크 + 스포츠(볼링)

## 1. 게임 구조

- 스테이지제: 목표 점수 이상 달성 시 즉시 클리어 후 다음 스테이지로 진행
  (발라트로처럼 목표 점수 개념을 가져오되, 목표 달성 즉시 클리어라는 점에서 차이)
- 경기 방식: 일반 볼링과 동일하게 총 10프레임, 프레임당 투구 2회
- 투구법: 별도 투구 스타일(폼) 도입 여부 논의 중 (보류)

## 2. 스킬 시스템 (로그라이크 핵심 요소)

### 발동형 (투구 시 확률적으로 발동, 큰 임팩트)
| 스킬 | 효과 |
|---|---|
| 지진 | 투구 후 확률적으로 캐릭터가 넘어지며 핀에 피해 |
| 스탠드 | 다른 캐릭터가 대신 투구 |
| 봅슬레이 | 썰매로 빠른 속도 투구 |
| 더블 | 공 하나가 추가로 같이 날아감 |
| 시한폭탄 | 투구 후 일정 시간 뒤 폭발 |
| 태풍 | 바람으로 주변 핀에 피해 |
| 부스터 | 투구 속도 증가 |
| 오류 | 핀 1개 남았을 때 확률적으로 자동으로 쓰러짐 |
| 거터 튕김 | 거터에 빠져도 다시 튀어나옴 |

### 상시형 (지속 발동, 보조 효과)
| 스킬 | 효과 |
|---|---|
| 상점 할인 | 상점가 할인 |
| 근력 | 파운드 증가 + 투구 속도 증가 |
| 투구 증가 | 프레임당 투구 횟수 +1 |
| 스페어 처리 | 특정 n프레임은 항상 스페어 처리(스페어/스트라이크 점수 2배) |
| 보너스 핀 | 보너스 핀 등장 빈도 증가 |

## 3. 상점

플레이어를 보조하는 장비 판매:
- 볼링화 - 넘어질 확률 감소
- 장갑(아대) - 투구 안정성 향상
- 볼링공 - 파운드 증가
- 기름 제거 수건 - 레인 기름기 제거

## 4. 맵 구성

### 레인 (지형 타입)
| 타입 | 특징 |
|---|---|
| 얼음 | 매우 미끄러움 |
| 모래 | 미끄러움 없음 |
| 기본(나무) | 표준 |
| 마그마블럭 | 진행 중 발화 |
| 트램펄린 | 힘이 부족하면 통과 불가 |

### 핀 (특수 핀)
| 핀 | 특징 |
|---|---|
| 보너스핀 | 스킬 획득 시 등장, 점수 추가 |
| 오뚜기핀 | 쓰러져도 확률적으로 재기립 |
| 철심 핀 | 파괴 판정 없인 쓰러지지 않음 |
| 부메랑 핀 | 2회 타격해야 쓰러짐 |
| 돌진 핀 | 공 쪽으로 돌진해 진로 방해 |

### 장애물
| 장애물 | 효과 |
|---|---|
| 바나나껍질 | 공이 미끄러짐 |
| 돌부리 | 공이 튀며 파워 감소 |
| 블랙홀 | 주변 공을 흡입 |

## 5. 투구 시스템 (조작 / 물리)

**입력 방식**
- 마우스를 누른 채 뒤로 뺐다가 앞으로 밀며 놓으면 투구
- (대안) 불편하면 앞으로 미는 동작만으로 투구되게 단순화 가능

**궤적 -> 물리 변환**
- 마우스 드래그 경로의 각도를 추적 -> 공의 진행 방향 결정
- 드래그 궤적의 곡률(휘어짐)에 따라 스핀(회전) 값 추가 -> 공이 커브를 그리며 이동
- 마우스 이동 속도 추적 -> 공의 투구 속도 결정

**데미지 공식**
```
충격력 = 속도 x 파운드
데미지 = 충격력 x 힘보정 x 회전보정
```
