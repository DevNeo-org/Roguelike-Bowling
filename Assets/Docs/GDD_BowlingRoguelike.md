# 볼링 로그라이크 (가제)

**장르**: 캐주얼 물리 스포츠 + 탐험형 로그라이크

> **레퍼런스**: **Walkabout Mini Golf**가 메인, **WHAT THE GOLF?**는 아주 가끔(보스급) 향신료로만.
> - Walkabout처럼: 핵심 동작(투구)은 끝까지 그대로 유지, 대신 **레인 하나하나가 공들여 만든 완결된 장소**. 실패해도 벌칙 없이 느긋하게 즐기는 톤.
> - WTG처럼: 규칙을 통째로 깨는 반전은 **한 런에 한두 번, 보스 스테이지 정도로만** 아껴서 사용.
> - 장애물(바나나껍질 등)과 레인 타입(얼음/모래 등)은 "방해 요소"가 아니라 **"이 장소라면 당연히 있을 법한 것"**으로 자연스럽게 녹여서 배치.

> **스킬 시스템은 삭제됨.** 대신 로그라이크 정체성을 어떻게 유지할지 논의 중 (아래 5번 항목 참고, 아직 미확정).

## 3. 맵 구성

### 레인 (지형 타입) - "장소에 자연스러운 이유"를 붙여서 테마화
| 타입 | 특징 |
|---|---|
| 얼음 | 매우 미끄러움 |
| 모래 | 미끄러움 없음 |
| 기본(나무) | 표준 |
| 마그마블럭 | 진행 중 발화 |
| 트램펄린 | 힘이 부족하면 통과 불가 |

### 핀 (레인 테마별 쓰러짐 연출)
핀의 기능/판정은 전부 동일함 (HP, 타격 횟수 등 성능 차이 없음). **레인 테마에 맞춰 쓰러지는 이펙트/사운드만 다르게** 연출.

| 레인 | 핀 재질/느낌 | 쓰러지는 연출 |
|---|---|---|
| 기본(나무) | 나무 볼링핀 | 평범하게 쿵 쓰러짐, 나무 부딪히는 소리 |
| 모래 | 모래로 뭉친 핀 | 와르르 무너져 내림, 모래 먼지 풀썩 + 사그락 소리 |
| 얼음 | 얼음을 깎아 만든 핀 | 쨍그랑 금 가고 파편 흩날림, 유리 부딪히는 소리 |
| 마그마 | 용암암석/왁스 느낌 핀 | 흐물흐물 녹아내림, 치익 소리 + 김 나는 이펙트 |
| 트램펄린 | 고무/젤리 재질 핀 | 통통 튀고서야 멈춤, 통통 소리 |

새 장소 추가 시에도 이 원칙(재질에 맞는 이펙트/사운드만 교체)을 따름. 보너스/오뚜기/철심/부메랑/돌진 핀 등 성능 차이가 있던 기존 특수 핀 기획은 전부 삭제.

### 장애물
| 장애물 | 효과 |
|---|---|
| 바나나껍질 | 공이 미끄러짐 |
| 돌부리 | 공이 튀며 파워 감소 |
| 블랙홀 | 주변 공을 흡입 |

레인 하나당 메인 기믹은 1개 원칙 (여러 개 겹치면 원인 파악이 안 돼서 웃김이 아니라 짜증이 됨).

## 4. 투구 시스템 (조작 / 물리)

**입력 방식**
- 마우스를 누른 채 뒤로 뺐다가 앞으로 밀며 놓으면 투구
- **투구 느낌 2종류**:
  - 뒤로 드래그 → 앞으로 밀면서 놓기: **바닥에서 미는 느낌**
  - 바로 앞으로 드래그하며 놓기: **던지는 느낌**

**궤적 -> 물리 변환**
- 드래그 각도 -> 진행 방향, 궤적 곡률 -> 스핀(회전), 드래그 속도 -> 투구 속도

**데미지 공식**
```
충격력 = 속도 x 파운드
데미지 = 충격력 x 힘보정 x 회전보정 x (1 + 기름기 x 0.01)
```
기름기 보정치를 실제로 어떤 요소와 연동할지는 미정.

## 5. 로그라이크 정체성 (논의 중, 미확정)

### 문제의식
스킬(성장)을 빼면서, "이번 런이 저번 런과 다르게 흘러간다"는 누적 감각 자체가 같이 빠졌음. 지금 구조는 스테이지가 다양해도 스테이지끼리 서로 독립적이라, 로그라이크보다는 "테마 모음집"에 가까움.

### 검토했던 두 방향
1. **퀘이크(성격) 컬렉션** - 힘이 아니라 "장난"이 쌓임. 스테이지 클리어할 때마다 정비 화면에서 하나씩 선택해 획득.
2. ~~런 정체성~~ - 런 시작 시 랜덤 컨셉 부여, 진행하며 관련 이벤트 증가. *(콘텐츠 부담 커서 후순위로 밀림)*

**1번(퀘이크 컬렉션) 쪽으로 기울었으나 아직 최종 확정은 아님.**

### 퀘이크 예시 (브레인스토밍, 미확정)
| 퀘이크 | 효과 | 비고 |
|---|---|---|
| 바나나 자국 | 공이 지나간 자리에 바나나 자국이 남고, 다음 투구 때 밟으면 미끄러짐 | 스스로 판 함정 |
| 핀 재채기 | 핀이 가끔 스스로 한 칸 움찔 이동 | 예측 불가 코미디 |
| 메아리 핀 | 핀 쓰러질 때 소리가 점점 크게 메아리침 (누적) | 청각 escalation |
| 끈끈이 신발 | 캐릭터가 가끔 바닥에 붙어서 넘어짐 | 캐릭터 애니메이션 개그 |
| 거울 핀 | 핀이 거울로 바뀜, 공 다가가면 반사 이펙트 | 시각 장식용 |
| 딸꾹질 공 | 공이 굴러가다 가끔 살짝 튀어오름 | 투구감 코미디 |
| 나비 떼 | 레인 위 나비가 공에 맞으면 흩어짐 (점수 무관) | 순수 연출용 |
| 그림자 분신 | 캐릭터 그림자가 반 박자 늦게 따라 움직임 | 미묘한 위화감 개그 |

원칙: 전부 방해 효과면 피로해지므로, **점수/플레이에 영향 없는 순수 연출용 퀘이크도 섞기**.
